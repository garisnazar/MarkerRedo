# 🎮 Private Telegram Bot

Телеграм-бот, который на команду `/start` отвечает, что он приватный, и объясняет, как получить доступ.

## Запуск

```bash
pip install -r requirements.txt

# Linux / macOS
export BOT_TOKEN="ваш_токен_от_BotFather"
# Windows (PowerShell)
# $env:BOT_TOKEN="ваш_токен_от_BotFather"

python bot.py
```

## Важно

Никогда не храните токен бота в коде и не загружайте его на GitHub.
